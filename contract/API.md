# API

仅适用于实际提供 API 的项目。资源设计和页面请求遵循 [DESIGN-REVIEW.md](DESIGN-REVIEW.md) DESIGN-03/05。

- 接口表达稳定领域语义，不直接暴露内部存储结构。跨实体读模型和业务动作明确命名，按真实消费者设计。
- HTTP 方法、状态码、错误和内容类型符合实际语义；GET 不做业务写入。错误对消费者有用，不泄露内部敏感信息。
- 服务端校验输入和对象权限；增长型列表限制读取范围、稳定排序、按需分页，避免全量读取后切片及 N+1。固定小集合无需机械分页。
- 有独立升级的消费者时处理兼容性与迁移；共同发布的内部接口可直接演进。只有外部集成、代码生成等确有收益时使用 OpenAPI 等机器可读接口描述，避免重复维护。
- 按真实消费者验证关键接口和页面，不以 schema 文件或路由存在证明行为正确。
