# Agent

设计或实质性修改前，先理解用户目标、项目 Owner 和真实实现，读取 [DESIGN-REVIEW.md](DESIGN-REVIEW.md) 及相关专题。用户引用 Backend Contract 复查设计时，先检查最高优先级 DESIGN-00，再以十项原则为入口，不要求安装或运行 CLI。

- 用户明确的原则优先；不将单一项目实现机械推广，不以框架、目录或通用最佳实践代替真实需求。
- 选择最简单的可行实现，复用现有能力。工程约束服务于产品，不增加重复事实、无价值机制、流程锁或无依据门禁。
- 开发中遵循适用规范，复用真实 Gate；完成后按 [REVIEW.md](REVIEW.md) 验证受影响行为。不能把测试通过或文件存在冒充整体正确。
