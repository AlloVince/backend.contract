# Gate

Gate 只保障真实、确定、可复现且值得防止的错误，不衡量文档合规。

- 复用项目已有测试、lint、类型检查、构建、CI 和数据库能力；没有实际缺口不新增门禁。
- 优先保护身份唯一性、数据完整性、实际安全边界和已发生的高价值错误。关键门禁验证合法行为不被误阻断。
- 领域建模、命名取舍、架构复杂度和性能判断留给 Agent / Review，不能靠关键词或无依据的数字判定。
- 不以规范文件、版本、Hash、基线登记、审批或检查数量阻止正常开发、测试、构建、重建或发布。冲突机制按 DESIGN-00 直接删除或修正；真实业务测试失败仍应如实报告并修复。
- 可选 CLI 的 check --run 只运行 backend-contract.json 中显式启用的命令；未配置或未运行如实提示，不算通过，也不是失败。真实命令错误、无效配置和越界操作返回失败。
